# PFx Paint Studio: imported brush presets

The following original `.myb` brush settings were copied without modification from [mypaint/mypaint-brushes](https://github.com/mypaint/mypaint-brushes) at commit `08da4a48a4b63f2e0f3303942d7c21da8479ea9f`.

Raw `.myb` brush settings in the official MyPaint repository are dedicated to the public domain / CC0 1.0. Only the raw `.myb` presets are included here; no preview images or GPL build scripts were copied.
